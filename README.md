# Rhitta Charged Blast

A single-script Luau ability system built for a Roblox VFX test place, submitted for the Luau Scripter skill role.

Hold **E** (Compress variant) or **V** (Giant variant) to charge a Rhitta-style fireball, release to launch it toward the mouse cursor. On impact it spawns a charge-scaled explosion, deals radial falloff damage, and shakes nearby cameras.

See [`RhittaChargedBlast.client.luau`](./RhittaChargedBlast.client.luau) for the full script and inline documentation covering CFrame math, raycast collision, Heartbeat simulation, metatables, runtime animation registration, and particle scaling.
